# 세컨드 브레인 사용 가이드 (PARA + CODE)

이 사이트는 Quartz 위키를 대신하는 한준모(weedmo)의 세컨드 브레인입니다. 정보는 **PARA**로 *어디에 둘지*를 정하고, **CODE**로 *얼마나 다듬어졌는지*를 버전으로 표시합니다.

## 1. PARA 대분류 (상단 메뉴)

| 대분류 | 넣는 것 | 예 |
|---|---|---|
| **0. Inbox** | 아직 분류하지 않은 메모, 막 수집한 자료. 주기적으로 비워서 아래 넷 중 하나로 옮긴다 | 이 가이드 |
| **1. Project** | 마감과 목표가 있는 진행 중 작업 | lerobot framework data 표준화 1차 (2026-10-14 ~ 2026-11-30), 오픈소스 기여 |
| **2. Area** | 마감 없이 계속 관리하는 책임 영역 | 커리어, 수료·자격 |
| **3. Resource** | 관심 주제별 참고 자료 | Robotics, AI/ML, Data Engineering, 학습 노트(Rokey-AI, ROS-study) |
| **4. Archive** | 끝났거나 비활성인 항목 | 두산 Rokey 부트캠프 (2025.01–07)와 그 저장소 프로젝트 |

- 프로젝트가 끝나면 문서를 **4. Archive**로 옮긴다(사이드바에서 끌어 놓기 또는 문서 메뉴 "다른 위치로 옮기기").
- 대분류 key(`inbox`, `project`, `area`, `resource`, `archive`)는 URL과 `meta.yaml`에 쓰이므로 바꾸지 않는다. 이름만 바꾼다.

## 2. CODE 흐름과 버전 규칙

| CODE 단계 | 버전 | 화면 상태 | 의미 |
|---|---|---|---|
| **C**apture (수집) | `v0.0` | draft | 처음 넣은 원본 메모·업로드. 다듬지 않음 |
| **O**rganize (정리) | `v0.1`, `v0.2` … | draft | 알맞은 PARA 위치로 옮기고 구조·링크를 정리 |
| **D**istill (요약) | `v0.x` 계속 | draft / review | 핵심만 남기고 요약, 한·영 내용 보강 |
| **E**xpress (표현) | `v1.0` 이상 | approved | 블로그·포트폴리오·Notion 등 밖으로 내보낼 수 있는 확정본 |

- 수정할 때마다 새 버전 폴더가 생기고 이전 버전은 그대로 남는다(사이트의 Markdown 편집 → 저장).
- 다 다듬었으면 문서 상단 상태 배지를 눌러 **정식 확정**(v0.x → v1.0)한다.
- 확정본을 다시 고치면 v1.1, 크게 바뀌면 v2.0.

## 3. 작성 규칙

- 페이지는 가능한 한 `## English` 다음 `## 한국어` 두 언어로 쓴다(기존 위키 규칙 유지).
- 사실만 적는다. 출처(저장소, 이슈, 원본 파일)를 문서 상단 인용 블록에 남긴다.
- 문서끼리는 `[제목](/대분류/메뉴/문서)` 링크로 연결한다. 편집기에서 `[[`를 입력하면 후보가 나온다.
- 이미지·PDF는 문서 버전 폴더 안(`images/`, `pdfs/`)에 두고 상대 경로로 건다.
- 원본 자료(`/home/box/second-brain/raw/`)는 수정하지 않는다.

## 4. Quartz 위키에서 옮긴 방식

- 기존 `wiki/` 페이지는 모두 **v0.1 (Organize)** 로 옮겼다. 확정한 것이 아니므로 하나씩 검토 후 v1.0으로 확정한다.
- `[[위키링크]]`는 사이트 링크로 바꿨고, frontmatter(tags, sources, updated)는 본문 상단 인용 블록으로 옮겼다.
- 노트북 출력 이미지 중 원래 위키에도 없던 것은 `(이미지 없음)`으로 표시했다.
