## English

Issuer of the Doosan Robotics Bootcamp completion certificate (**2025-07-05**) for [Joonmo Han (weedmo) / 한준모](/area/career/joonmo-han).

Bootcamp project arc and linked GitHub work: [Doosan Rokey Bootcamp / 두산 Rokey 부트캠프](/archive/doosan-rokey-bootcamp/doosan-rokey-bootcamp) (source collection [weedmo Rokey / Doosan bootcamp GitHub repos / weedmo Rokey·두산 부트캠프 저장소 모음](/archive/doosan-rokey-bootcamp/weedmo-rokey-repos)). Several projects use the **Doosan M0609** manipulator (e.g. [rokey-easy-moveit2 / Rokey MoveIt2 Task Server](/archive/doosan-rokey-bootcamp/rokey-easy-moveit2), [Rokey-Collaboration1 / Domino (M0609)](/archive/doosan-rokey-bootcamp/rokey-collaboration1), [D-Cashier- / Smart cashier cobot](/archive/doosan-rokey-bootcamp/d-cashier), [robo-calligraphy / Manipulator handwriting](/archive/doosan-rokey-bootcamp/robo-calligraphy)).
