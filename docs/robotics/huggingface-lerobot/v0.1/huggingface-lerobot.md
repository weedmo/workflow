## English

Open-source robot learning library and dataset tooling under Hugging Face.

[Joonmo Han (weedmo) / 한준모](/area/career/joonmo-han) contributed investigation and a proposed fix around cumulative `from_timestamp` drift on concatenated episode videos: [LeRobot](/project/open-source-contributions/lerobot-issue-3177) and [LeRobot PR](/project/open-source-contributions/lerobot-pr-3179). See [Open source contributions / 오픈소스 기여](/project/open-source-contributions/open-source-contributions).
